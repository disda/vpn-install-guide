VPN 客户端安装教程

按你的操作系统选择客户端：下载安装包 → 导入订阅 → 开启代理 → 测试连接

所有下载按钮均指向各客户端的官方发布渠道（GitHub 发布页、App Store、项目官网）

开始之前：先拿到你的订阅地址

  1. 打开你的订阅服务商网站并登录你的账号（没有账号先在服务商官网注册）。
  2. 进入账号控制台，复制你账号专属的 Clash 订阅地址 备用。后面每个客户端的「导入订阅」用的都是这个地址。
  3. 按你的设备系统，在下面选择对应的客户端，下载安装包并安装。
  4. 把订阅地址粘贴到客户端里导入，再开启系统代理，最后打开 google.com 测试。
⚠️ 订阅地址是你账号的专属凭证，等同于密码：不要截图发给别人、不要贴到公开场合。泄露后请回服务商官网重置。

说明：Clash 开源项目已经停止更新，Clash for Windows 与 ClashX 也随之停更。建议优先使用仍在维护的客户端，如 Mihomo Party、FlClash、sing-box、Stash、Shadowrocket 等。本页保留了 CFW / ClashX 的旧教程步骤，方便存量用户对照，但不再提供其下载。

Windows

Mihomo Party（Clash Party）推荐

下载 Windows 版（2.0.4 x64） GitHub 发布页（更多版本）
  1. 点击下载并安装。
  2. 复制你的 Clash 订阅地址（见页首说明）。
  3. 点击左侧订阅卡片，在右侧订阅管理面板的输入框中粘贴并导入。
  4. 点击系统代理卡片，开启代理上网。打开 google.com 测试。

FlClash推荐

下载 Windows 版（0.9.3 amd64） GitHub 发布页（更多版本）
  1. 点击下载并安装。
  2. 选择 Profiles（配置）面板，点击右下角添加按钮，新增订阅链接，粘贴你的订阅地址。
  3. 选择 Dashboard（仪表盘）面板：System Proxy 选择开启，Outbound Mode 选择 Rule（规则模式），点击右下角开始按钮。
  4. 打开 google.com 测试。

模式说明：规则模式（推荐）按配置文件规则自动分流；全局模式所有流量都走代理；直连模式相当于关闭代理。遇到不走系统代理的应用（如 Telegram、命令行工具），可在 Dashboard 开启 TUN 模式接管全部流量，Windows 下需以管理员身份运行。

  2. 启动服务后打开 google.com 测试。

Clash for Windows已停更 · 仅保留步骤

该客户端已停更、官方仓库已下线，本站不再提供下载；以下步骤供已安装的用户参考，新用户请用上面的客户端。

  1. 右键以管理员权限运行 Clash 客户端，在 Profiles 面板添加订阅地址，并点击下载按钮。

ClashMac

前往 clashmac.app 下载 ClashMac
  1. 解压下载的 zip 文件，把 ClashMac.app 拖入「应用程序」文件夹；首次启动时右键点击应用选择「打开」。
  2. 复制你的订阅链接，并添加到应用中。
  3. 点击右上角菜单栏的 ClashMac 图标，选择 Network Takeover，再选择 TUN / Proxy，或同时选择。

遇到「已被阻止打开」的安全提示：打开系统设置 → 隐私与安全性，向下滚动找到该提示，点击旁边的「仍要打开」，再在弹窗中确认一次。ClashMac 需要 macOS 11.0（Big Sur）或更高版本；首次运行会请求添加 VPN 配置的权限，必须点「允许」。

iOS / iPad

下面的客户端大多是美区 App Store 的付费应用，需要美区 Apple ID 购买，请提前准备好美区账号。

Shadowrocket（小火箭）推荐

  1. 安装小火箭（Shadowrocket）。小火箭是美区付费 App，需要在美区 App Store 购买。
  2. 进入 App 后，点击左上角的扫描按钮，扫描服务商提供的二维码导入。
  3. 同步节点后，选择第一个节点。
  4. 开启连接，此时系统会请求 VPN 权限，允许后配置就完成了。
  5. 打开 google.com 测试。
  6. 日后更新配置：滑动小火箭里导入的那个配置，即可完成一次配置文件更新。

如果不能扫码，也可以在小火箭里通过 URL 订阅：新增订阅并粘贴你的订阅地址。

  1. 在美区 App Store 购买 Stash（或通过充值兑换码在美区 App Store 充值后购买，需要登录美区 ID）。
  2. 点击 Stash 左上角图标，选择导入 → 从 URL 下载，并输入你的订阅地址，点击下载。
  3. 选择配置文件为刚导入的那一个。
  4. 回到 Stash 主界面，点击启动。
  5. 如果遇到问题，请确保系统升级到 iOS 15.0 以上。

Loon / Quantumult X有限支持

Loon 与 Quantumult X 都是美区付费软件，请自行购买。这两个客户端仅支持部分服务器，推荐优先使用 Stash / Shadowrocket / Clash。

  • Loon：进入 Loon，点击 Profile → Download from URL，在弹窗中输入服务商提供的 Loon 配置文件地址后同步。
  • Quantumult X：点击右下角三角，在节点部分选择「引用订阅」，输入服务商提供的节点订阅文件地址后同步；回到首页展开最新订阅选择节点，再点右上角代理开关。Quantumult X 功能复杂，不适合一般用户；服务商通常仅提供节点文件，不提供规则等其他配置。

备注：Quantumult X / Shadowrocket 不支持自动测速，服务商一般只提供部分速度和可用性较高的节点，手动选择更方便；全部节点只在支持 Clash 的软件上提供。

服务器 / 终端（无桌面环境）

  1. 下载 Clash / Mihomo 核心程序并在终端运行，同时下载你的配置文件（订阅地址对应的 config.yaml）。
  2. 启动成功后，可通过 Web 界面 http://127.0.0.1:9090/ui 管理。
  3. 核心默认在 7890 端口提供 HTTP 代理、7891 端口提供 SOCKS 代理；把其他程序（浏览器 / Git / NPM 等）设置为使用这些代理端口即可。也可以用环境变量方式：export https_proxy=http://127.0.0.1:7890 http_proxy=http://127.0.0.1:7890。

提示：ping 命令不支持代理，请用 curl 或 wget 测试连通性。

常见问题

订阅 / 配置文件下载失败？

先关闭系统代理再重新订阅；还不行就把系统 DNS 改为 119.29.29.29 再试。

连上了但打不开网页？

确认客户端里选中的是刚导入的配置、出站模式是 Rule（规则）而不是 Direct（直连），并确认系统代理开关已打开。可以打开 ifconfig.me 检查出口 IP 是否已变化。

Clash for Windows 报错？

点击 General → Home Directory，删除目录里的文件和子目录，再重新订阅一次。

节点怎么选？

在客户端的 Proxies（代理）面板里，先选代理组再点节点；把代理组选为 Auto 可自动测速选最快节点。配置文件里不同代理组针对不同服务做了优化（如流媒体、AI 服务），按常用服务选对应组即可。

订阅地址泄露了怎么办？

回服务商官网的账号控制台重置订阅地址，旧地址会立即失效，然后在各客户端里换成新地址重新导入。
